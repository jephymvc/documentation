# Overview

{{ site.title }} is a lightweight, modular PHP MVC framework built for developers who want clean architecture, high performance, and full control over their web applications. It follows the Model-View-Controller pattern to separate business logic, presentation, and data handling—making your code more maintainable, scalable, and testable.

Template Engine: Unlike many lightweight frameworks that rely on raw PHP in views, {{ site.title }} natively integrates the Smarty Engine—a powerful, feature-rich template system that keeps your presentation layer clean, secure, and easy to manage.

Key Features

  • Modular MVC Structure – Clear separation of concerns with Models, Views, and Controllers.
  • Smarty Template Engine – Write clean, logic-free templates with caching, layouts, custom functions, and built-in security against XSS.
  • Simple Routing – Define clean, RESTful routes with support for dynamic parameters and middleware.
  • Lightweight & Fast – Minimal overhead with no unnecessary dependencies.
  • Database Abstraction – Built-in query builder and active record pattern (or ORM).
  • Middleware Support – Filter HTTP requests before they reach your controllers.
  • Request & Response Handling – Object-oriented wrappers for input, session, cookies, and output.
  • CSRF & XSS Protection – Built-in security helpers (Smarty auto-escaping adds an extra layer).
  • Error Handling & Debugging – Custom error pages and debug mode with detailed logs.

# Installation

To install JephyPHP, visit {{site.repo_url}} and clone the repository or download the zip file.

Working with XAMPP or any LAMP/WAMP system

If you are working with option 1 of the requirements, extract the zip file and copy the contents of /version-x.x/src into the C:/xampp/htdocs or /xampp/htdocs(depending on your device's operating system directory structure from the root path). You will get directories jephy-mvc/, public/, vendor/, composer.json and composer.lock.

You do not really have to retain the directory structure as it is. You can decide to have every other directories outside of the C:/xampp/htdocs of /xampp/htdocs path. But you must have your static files somewhere within the path of C:/xampp/htdocs or /xampp/htdocs.

Shared Hosting with Apache

If you are working on shared hosting (especially with cPanel), extract the zip file and copy the contents of /version-x.x/src/public into the /.../public_html folder. You can decide to have the version-x.x/src/jephy-mvc/ and version-x.x/src/vendor/ path as a sibling directories to the /.../public_html folder. The same also applies to working with XAMPP/WAMP system.

See more on Shared Hosting Deployment.

Shared Hosting with Nginx

If you are working on shared hosting (especially with cPanel), extract the zip file and copy the contents of /version-x.x/src/public into the /.../html folder. You can decide to have the version-x.x/src/jephy-mvc/ and version-x.x/src/vendor/ path as a sibling directories to the /.../html folder.

See more on Shared Hosting Deployment.

Make sure you run the following composer code in the path you have composer.json and composer.lock. 

composer dump-autoload

Cloud/VPS/Dedicated Server Hosting

We strongly recommend that you work with a dockerization setup. Ensure you have docker setup runtime installed on the machine and build image of the app from path /version-x.x/. You also have the option to choose between working with the default Dockerfile or running the docker-compose.yml

See more on VPS/Dedicated Server Deployment.

However, you will need a reverse-proxy server setup in between your application docker instances and the public. See more on VPS/Dedicated Server Deployment.

Working with Dockerfile

Run the following command to build your app image: 

docker build -t jephy-mvc-app-image-name ./

N.B.:Use can what is comfortable for you for jephy-mvc-app-image-name

Run the following command to run your container: 

docker run -d --name jephy-mvc-app-container-name -p 8080:80 jephy-mvc-app-image-name

N.B.:Use what is comfortable for you for jephy-mvc-app-container-name and remember that jephy-mvc-app-image-name still refers to your chosen image name above.

However, you must ensure your jephy-mvc/config.conf is properly configured to your chosen path for the following fields:

  • -> site.app_path: defaults to {your_absolute_path}/jephy-mvc/app.
  • -> site.home_root_path: defaults to this is usually your {your_absolute_path}/htdocs/ or {your_absolute_path}/public_html/ folder
  • -> smarty.template_dir: defaults to {your_absolute_path}/jephy-mvc/app/views/.
  • -> smarty.compile_dir: defaults to {your_absolute_path}/jephy-mvc/app/cache/views_c/.
  • -> smarty.cache_dir: defaults to {your_absolute_path}/jephy-mvc/app/cache/.

The beautiful part, is that you actually have control over what absolute directory path should serve what purpose. This makes it possible to keep your sensitive data out of the public path without breaking anything.

# Basic Usage Example

This section walks you through creating a complete working example from scratch - a simple blog system with user authentication and article management.

Step 1: Database Setup

First, create your database tables:

sql

-- users table
CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(255) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL,
    role ENUM('admin', 'user') DEFAULT 'user',
    status ENUM('active', 'inactive') DEFAULT 'active',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- posts table
CREATE TABLE posts (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
    title VARCHAR(255) NOT NULL,
    slug VARCHAR(255) NOT NULL UNIQUE,
    content TEXT NOT NULL,
    excerpt VARCHAR(500),
    featured_image VARCHAR(255),
    status ENUM('draft', 'published') DEFAULT 'draft',
    views INT DEFAULT 0,
    published_at DATETIME,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

-- categories table
CREATE TABLE categories (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    slug VARCHAR(100) NOT NULL UNIQUE,
    description TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- post_categories table (many-to-many)
CREATE TABLE post_categories (
    post_id INT NOT NULL,
    category_id INT NOT NULL,
    PRIMARY KEY (post_id, category_id),
    FOREIGN KEY (post_id) REFERENCES posts(id) ON DELETE CASCADE,
    FOREIGN KEY (category_id) REFERENCES categories(id) ON DELETE CASCADE
);

-- comments table
CREATE TABLE comments (
    id INT AUTO_INCREMENT PRIMARY KEY,
    post_id INT NOT NULL,
    user_id INT,
    author_name VARCHAR(100),
    author_email VARCHAR(255),
    content TEXT NOT NULL,
    status ENUM('pending', 'approved', 'spam') DEFAULT 'pending',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (post_id) REFERENCES posts(id) ON DELETE CASCADE,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE SET NULL
);

// jephy-mvc/app/models/Post.php
namespace App\Models;

use Core\Model;

class Post extends Model
{
    protected $table = 'posts';
    protected $fillable = ['user_id', 'title', 'slug', 'content', 'excerpt', 'featured_image', 'status', 'published_at'];
    
    public function author()
    {
        return $this->belongsTo(User::class, 'user_id');
    }
    
    public function categories()
    {
        return $this->belongsToMany(Category::class, 'post_categories', 'post_id', 'category_id');
    }
    
    public function comments()
    {
        return $this->hasMany(Comment::class, 'post_id')->where('status', 'approved');
    }
    
    public function publish()
    {
        $this->status = 'published';
        $this->published_at = date('Y-m-d H:i:s');
        $this->save();
    }
    
    public function incrementViews()
    {
        $this->views++;
        $this->save();
    }
}

// jephy-mvc/app/controllers/PostController.php
namespace App\Controllers;

use Core\Controller;
use App\Models\Post;
use App\Models\Category;
use App\Models\Comment;

class PostController extends Controller
{
    public function index()
    {
        $page = (int) ($_GET['page'] ?? 1);
        $perPage = 10;
        $category = $_GET['category'] ?? null;
        
        $query = Post::where('status', 'published');
        
        if ($category) {
            $query->whereHas('categories', function($q) use ($category) {
                $q->where('slug', $category);
            });
        }
        
        $posts = $query->orderBy('published_at', 'DESC')
            ->paginate($perPage, $page);
        
        $this->view->set('posts', $posts);
        $this->view->set('currentCategory', $category);
        $this->view->set('pageTitle', $category ? "Category: {$category}" : 'All Posts');
        
        return $this->view->display('posts.index');
    }
    
    public function show($slug)
    {
        // Find post by slug
        $post = Post::where('slug', $slug)->where('status', 'published')->first();
        
        if (!$post) {
            return $this->notFound();
        }
        
        // Increment view count
        $post->incrementViews();
        
        // Get comments for this post
        $comments = $post->comments()->where('status', 'approved')
            ->orderBy('created_at', 'DESC')
            ->get();
        
        // Get related posts (same categories)
        $categoryIds = $post->categories()->pluck('id')->toArray();
        $relatedPosts = Post::whereHas('categories', function($q) use ($categoryIds) {
                $q->whereIn('id', $categoryIds);
            })
            ->where('id', '!=', $post->id)
            ->where('status', 'published')
            ->limit(3)
            ->get();
        
        $this->view->set('post', $post);
        $this->view->set('comments', $comments);
        $this->view->set('relatedPosts', $relatedPosts);
        $this->view->set('pageTitle', $post->title);
        
        return $this->view->display('posts.show');
    }
    
    public function comment($postId)
    {
        $post = Post::find($postId);
        
        if (!$post) {
            return $this->json(['error' => 'Post not found'], 404);
        }
        
        $data = $this->request->post();
        
        // Simple validation
        if (empty($data['content'])) {
            return $this->json(['error' => 'Comment content is required'], 422);
        }
        
        $commentData = [
            'post_id' => $postId,
            'content' => $data['content'],
            'status' => 'pending' // Requires moderation
        ];
        
        if (isset($_SESSION['user_id'])) {
            $commentData['user_id'] = $_SESSION['user_id'];
        } else {
            if (empty($data['author_name']) || empty($data['author_email'])) {
                return $this->json(['error' => 'Name and email are required for guests'], 422);
            }
            $commentData['author_name'] = $data['author_name'];
            $commentData['author_email'] = $data['author_email'];
        }
        
        $comment = Comment::create($commentData);
        
        // Trigger notification hook
        $this->hookManager->fire('comment_created', $comment);
        
        return $this->json([
            'success' => true,
            'message' => 'Comment submitted for moderation',
            'comment' => $comment
        ], 201);
    }
}

php
// jephy-mvc/app/controllers/AuthController.php
namespace App\Controllers;

use Core\Controller;
use App\Models\User;

class AuthController extends Controller
{
    public function showLogin()
    {
        if (isset($_SESSION['user_id'])) {
            $this->redirect('/dashboard');
        }
        
        $this->view->set('pageTitle', 'Login');
        return $this->view->display('auth.login');
    }
    
    public function login()
    {
        $email = $this->request->post('email');
        $password = $this->request->post('password');
        $remember = $this->request->post('remember') === 'on';
        
        // Validate input
        if (empty($email) || empty($password)) {
            $_SESSION['flash_message'] = 'Email and password are required';
            $_SESSION['flash_type'] = 'error';
            $this->redirect('/login');
        }
        
        // Find user
        $user = User::where('email', $email)->first();
        
        if ($user && password_verify($password, $user->password)) {
            // Check if user is active
            if (!$user->isActive()) {
                $_SESSION['flash_message'] = 'Your account is inactive. Please contact admin.';
                $_SESSION['flash_type'] = 'error';
                $this->redirect('/login');
            }
            
            // Set session
            $_SESSION['user_id'] = $user->id;
            $_SESSION['user_name'] = $user->name;
            $_SESSION['user_role'] = $user->role;
            
            // Regenerate session ID for security
            session_regenerate_id(true);
            
            // Set remember me cookie
            if ($remember) {
                $token = bin2hex(random_bytes(32));
                $user->remember_token = $token;
                $user->save();
                setcookie('remember_token', $token, time() + 86400 * 30, '/', '', true, true);
            }
            
            // Update last login
            $user->last_login_at = date('Y-m-d H:i:s');
            $user->last_login_ip = $_SERVER['REMOTE_ADDR'];
            $user->save();
            
            // Redirect to intended page or dashboard
            $redirectTo = $_SESSION['intended_url'] ?? '/dashboard';
            unset($_SESSION['intended_url']);
            
            $this->redirect($redirectTo);
        }
        
        $_SESSION['flash_message'] = 'Invalid email or password';
        $_SESSION['flash_type'] = 'error';
        $this->redirect('/login');
    }
    
    public function showRegister()
    {
        if (isset($_SESSION['user_id'])) {
            $this->redirect('/dashboard');
        }
        
        $this->view->set('pageTitle', 'Register');
        return $this->view->display('auth.register');
    }
    
    public function register()
    {
        $data = $this->request->post();
        
        // Validate data
        $errors = [];
        
        if (strlen($data["name"]) < 2) {
            $errors["name"] = "Name must be at least 2 characters";
        }
        
        if (!filter_var($data['email'], FILTER_VALIDATE_EMAIL)) {
            $errors['email'] = 'Invalid email address';
        }
        
        if (strlen($data['password']) < 6) {
            $errors['password'] = 'Password must be at least 6 characters';
        }
        
        if ($data['password'] !== $data['password_confirmation']) {
            $errors['password_confirmation'] = 'Passwords do not match';
        }
        
        // Check if email exists
        if (User::where('email', $data['email'])->exists()) {
            $errors['email'] = 'Email already registered';
        }
        
        if (!empty($errors)) {
            $_SESSION['flash_message'] = 'Please fix the errors below';
            $_SESSION['flash_type'] = 'error';
            $_SESSION['validation_errors'] = $errors;
            $this->redirect('/register');
        }
        
        // Create user
        $user = User::create([
            'name' => $data['name'],
            'email' => $data['email'],
            'password' => password_hash($data['password'], PASSWORD_DEFAULT),
            'role' => 'user',
            'status' => 'active'
        ]);
        
        // Auto-login after registration
        $_SESSION['user_id'] = $user->id;
        $_SESSION['user_name'] = $user->name;
        $_SESSION['user_role'] = $user->role;
        
        $_SESSION['flash_message'] = 'Registration successful! Welcome!';
        $_SESSION['flash_type'] = 'success';
        
        $this->redirect('/dashboard');
    }
    
    public function logout()
    {
        // Clear session
        $_SESSION = [];
        
        // Delete session cookie
        if (ini_get("session.use_cookies")) {
            $params = session_get_cookie_params();
            setcookie(session_name(), '', time() - 42000,
                $params["path"], $params["domain"],
                $params["secure"], $params["httponly"]
            );
        }
        
        // Destroy session
        session_destroy();
        
        // Delete remember me cookie
        setcookie('remember_token', '', time() - 3600, '/', '', true, true);
        
        $this->redirect('/');
    }
}

// 1. Create middleware class
// jephy-mvc/app/middleware/RateLimitMiddleware.php
namespace App\Middleware;

use Core\Middleware;

class RateLimitMiddleware extends Middleware
{
    public function handle($request, $next)
    {
        $ip = $_SERVER['REMOTE_ADDR'];
        $key = "rate_limit:{$ip}";
        
        if (!isset($_SESSION[$key])) {
            $_SESSION[$key] = ['count' => 1, 'first_request' => time()];
        } else {
            if (time() - $_SESSION[$key]['first_request'] < 60) {
                if ($_SESSION[$key]['count'] >= 60) {
                    return $this->json(['error' => 'Too many requests'], 429);
                }
                $_SESSION[$key]['count']++;
            } else {
                $_SESSION[$key] = ['count' => 1, 'first_request' => time()];
            }
        }
        
        return $next($request);
    }
}

// 2. Apply to routes
$router->post('/api/submit', 'ApiController@submit')->middleware('RateLimitMiddleware');

// 1. Display form
public function showForm()

// 2. Process form submission
public function processForm()
{
    // Validate CSRF token
    if (!hash_equals($_SESSION['csrf_token'], $_POST['csrf_token'])) {
        throw new \Exception('CSRF attack detected');
    }
    
    // Get form data
    $name = $this->request->post('name');
    $email = $this->request->post('email');
    $message = $this->request->post('message');
    
    // Validate
    $errors = [];
    if (empty($name)) $errors['name'] = 'Name is required';
    if (!filter_var($email, FILTER_VALIDATE_EMAIL)) $errors['email'] = 'Invalid email';
    if (empty($message)) $errors['message'] = 'Message is required';
    
    if (!empty($errors)) {
        $_SESSION['form_errors'] = $errors;
        $_SESSION['old_input'] = $_POST;
        $this->redirect('/contact');
    }
    
    // Process data
    MailService::send($email, 'Contact Form', $message);
    
    $_SESSION['flash_message'] = 'Message sent successfully!';
    $this->redirect('/contact/thank-you');
}

public function uploadAvatar()
{
    if (isset($_FILES['avatar']) && $_FILES['avatar']['error'] === UPLOAD_ERR_OK) {
        $allowedTypes = ['image/jpeg', 'image/png', 'image/gif'];
        $maxSize = 5 * 1024 * 1024; // 5MB
        
        if (!in_array($_FILES['avatar']['type'], $allowedTypes)) {
            $_SESSION['flash_message'] = 'Invalid file type';
            $this->redirect('/profile');
        }
        
        if ($_FILES['avatar']['size'] > $maxSize) {
            $_SESSION['flash_message'] = 'File too large';
            $this->redirect('/profile');
        }
        
        // Generate unique filename
        $extension = pathinfo($_FILES['avatar']['name'], PATHINFO_EXTENSION);
        $filename = uniqid() . '.' . $extension;
        $uploadPath = UPLOAD_DIR . '/avatars/' . $filename;
        
        move_uploaded_file($_FILES['avatar']['tmp_name'], $uploadPath);
        
        // Save filename to database
        $user = User::find($_SESSION['user_id']);
        $user->avatar = $filename;
        $user->save();
        
        $_SESSION['flash_message'] = 'Avatar uploaded successfully!';
    }
    
    $this->redirect('/profile');
}
